# 논리공방 · 논리학 연습실

자연연역 65문제, 진리나무 19문제, 전통 논리 10문제를 세 탭에서 연습하는 정적 웹사이트입니다. 힌트, 검증된 예시 풀이, 원문 PDF 4개가 포함되어 있습니다.

## Windows 바탕화면에 폴더 만들기

1. ZIP을 다운로드한 뒤 **모두 압축 풀기**를 선택합니다. ZIP 안에서 바로 실행하지 마세요.
2. 압축을 푼 `logical_midterm` 폴더에서 `install-to-desktop.cmd`를 더블클릭합니다.
3. 현재 Windows 사용자의 실제 바탕화면(OneDrive 바탕화면 포함)에 `logical_midterm` 폴더가 만들어집니다.
4. 그 폴더의 `open-site.cmd`를 더블클릭하면 로컬 사이트가 열립니다.

같은 이름의 폴더가 이미 있으면 날짜와 시간을 붙인 새 폴더를 만들며 기존 폴더를 덮어쓰지 않습니다. 이미 목적지 폴더에서 실행했다면 해당 폴더를 엽니다. 설치 프로그램 없이 직접 바탕화면에 압축을 풀어도 됩니다.

## 바로 열기

`dist/index.html`을 Chrome이나 Edge로 열면 됩니다. 서버나 npm 패키지 설치 없이 동작합니다. 인터넷이 없어도 PDF, 규칙 안내, 증명 검증을 사용할 수 있습니다.

진행 상황은 브라우저에 저장됩니다. 온라인 사이트와 로컬 파일, 서로 다른 브라우저의 기록은 별도입니다. 온라인 사이트의 기존 풀이 기록은 이번 정렬 변경 시 문제 ID를 기준으로 자동 이전됩니다.

## 문제 편집 및 검증

문제 원본을 편집하고 풀이를 다시 생성할 때는 Node.js가 필요합니다. 외부 npm 의존성은 없습니다. 폴더 안에서 터미널을 열고 실행합니다.

```bash
npm run build
npm test
```

문제 수를 변경하면 `checks/classroom.test.cjs`의 총문제 수 검사도 함께 갱신하세요.

문제를 추가할 때는 고유한 `id`를 사용하세요. 기존 ID는 풀이 기록과 연결되므로 변경하지 않는 것이 좋습니다. `h4`, `h41`, `h5`, `own` 함수 호출에서 전제, 목표, 힌트를 작성합니다. `solution`은 `[명제, 규칙, 근거]`의 배열입니다. 풀이를 생략하면 생성기가 기본 규칙으로 탐색하고 검증합니다.

검사는 65개 예시 풀이의 모든 단계와 가정 해제를 검증하고, 진리표로 모든 문제의 타당성을 확인합니다. 저장 기록의 문제 ID 변환도 검사합니다.

## 진리나무 연습

사이트의 **진리나무** 탭 또는 URL 끝의 `#tree`로 들어갑니다.

1. 문제를 고르고 작업할 끝 가지를 선택합니다. 시작 집합은 문제 유형에 맞춰 자동 생성합니다.
2. 분해할 줄과 규칙을 선택하고 결과를 직접 입력합니다. 같은 가지의 문장은 `A; B`처럼 구분합니다. 가지치기가 필요할 때만 오른쪽 입력란도 사용합니다.
3. 모순인 두 줄을 인용해 ×로 닫거나, 완전히 분해된 모순 없는 가지를 ○로 표시합니다.
4. 판정을 선택하고, 열린 가지가 있으면 각 명제 문자의 T/F를 입력해 제출합니다.

풀이·진리값 입력·완료 기록은 `logicWorkshopTreesV1`에 저장하며 기존 자연연역 기록과 분리됩니다. 예시 풀이는 내 풀이와 완료 기록을 변경하지 않습니다.

핸드아웃 6에서 일관성 8문제(풀이 예제 포함), 타당성 5문제, 논리적 참 2문제, 논리적 거짓 2문제, 동치 2문제를 수록했습니다. p.10과 p.11의 중복 번호는 쪽수로 구별하고, p.15의 빠진 닫는 괄호를 보완했으며, p.18의 중복 문제는 한 번만 넣었습니다.

`checks/tree.test.cjs`는 모든 문제를 전체 진리값 배정과 대조하고, 9개 규칙의 의미 보존, 다른 가지 인용 거부, 재분해 거부, 가지 판정, 반례와 저장 풀이 재생을 검사합니다.

## 전통 논리 · 벤다이어그램

`#traditional` 또는 전통 논리 탭에서 핸드아웃 2의 9절, 1~10번을 풉니다. 전제의 음영과 X 후보 집합을 직접 표시하고, 타당성 및 필요한 반례를 제출합니다. 7번은 불과 아리스토텔레스 해석을 모두 풀어야 완료되므로 총 11개 판정을 연습합니다. 9번은 명제 유형과 번역 방향도 확인합니다. 10번의 특정 장소는 단일 원소 집합으로 해석합니다.

- `dist/traditional-logic.js`: 문제 원문, 8개 영역 의미론, 다이어그램·반례 검증
- `dist/traditional-app.js`: SVG 벤다이어그램, 입력, 해설, 별도 저장 기록
- `dist/traditional.css`: 전통 논리 화면 스타일
- `dist/method-tabs.js`: 세 학습 방법의 탭 및 키보드 전환
- `checks/traditional.test.cjs`: 10문제·11판정, 독립 유한 모델 검사, 잘못된 음영·존재·번역·반례 거부

저장 키는 `logicWorkshopTraditionalV1`입니다. 기존 자연연역과 진리나무 기록은 유지됩니다. X 후보 여러 개는 여러 대상이 아니라, 그 후보 중 적어도 하나에 존재하는 대상 하나를 뜻합니다.

전통 논리 문제의 출처는 핸드아웃 2의 p.19–20입니다. 이 핸드아웃의 PDF 전체는 공개 저장소에 포함하지 않습니다.
